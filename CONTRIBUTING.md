# Contributions and attribution

This repository begins as a personal portfolio index. Project pages describe local evidence and intended public artifacts; they do not represent independently reproducible public releases yet.

## Standards for a public project release

- Confirm code ownership and redistribution rights, including collaborators, third-party repositories, fonts, artwork and competition restrictions.
- Replace private paths, contact information, credentials, direct device endpoints and actual lab serial configuration with documented examples.
- Do not commit any raw participant signal, identifying metadata or real experiment log without separate, explicit permission.
- Freeze claims to the reproduced output; maintain the evaluation setup and separate numerical-engineering tests from human-science conclusions.
- Provide a minimal runnable example, dependencies, tests, a known output and a short limitations section.
- Keep development materials and archival evidence in their private source repositories.

No blanket license is granted for project code that has not been separately approved for release. A project-specific LICENSE will be included when the owner confirms permitted terms.
